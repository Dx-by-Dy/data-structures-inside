# Задача 1. Биты и hex

*Разминка. Нужна, чтобы привыкнуть: число — это набор битов, а не абстракция.*

## Что написать

Программу `01-binary.c`, которая читает целые числа до конца ввода и печатает
для каждого три представления: двоичное (32 бита, байты через пробел),
шестнадцатеричное (8 цифр) и десятичное — сначала как `int`, потом как
`unsigned int`.

```
$ printf '37\n-1\n' | ./01-binary
00000000 00000000 00000000 00100101
0x00000025
int      37
unsigned 37
11111111 11111111 11111111 11111111
0xFFFFFFFF
int      -1
unsigned 4294967295
```

## Сначала на Python

Прежде чем открывать `01-binary.c`, напечатайте то же самое на Python:

```python
v = 37
print(format(v, '032b'))
```

А теперь подставьте `v = -1` и посмотрите, что получилось. Тридцати двух
единиц там не будет — объясните, почему, и скажите, чего именно нет у
питоновского `int`, чтобы они появились.

## Проверьте себя

```sh
./01-binary --check
```

Скелет прогонит краевые случаи: ноль, единица, `-1`, `INT_MAX`, `INT_MIN`,
`255` и `-256`. Печатать биты вы обязаны через `putchar`, буферов в этой задаче
нет — поэтому сравнивать здесь приходится глазами, и правильная строка
печатается прямо под вашей. Они должны совпасть посимвольно. В остальных
задачах курса `--check` сверяет сам.

Три случая стоит разобрать отдельно. Для `INT_MIN` скажите **до** запуска,
сколько единиц будет в двоичной записи и где они стоят, а потом сверьте с
выводом. У `-1` и `-256` посмотрите на последнюю строку: как одно и то же число
оказывается отрицательным в одной строке и огромным положительным в соседней.
И сравните `255` с `-256`.

## Требования

- Переменная, в которой вы храните число для побитовой печати, — **строго
  `uint32_t`** из `<stdint.h>`. Почему не `int` — разберитесь сами, этот вопрос
  задаётся на защите.
- Никаких массивов и строк: печатайте биты по одному через `putchar`.
- Собирается без предупреждений.

## Подсказки

- Прочитать число: `scanf("%d", &n)`. Проверьте, что `scanf` вернул `1`, — иначе
  в `n` остался мусор, а вы его напечатаете.
- Взять `i`-й бит числа `v`: `(v >> i) & 1u`. Старший бит — 31-й, печатать надо
  с него, то есть цикл идёт вниз.
- Пробел после байта ставится, когда `i % 8 == 0` и `i != 0`.
- Приведение `int` к `uint32_t` не меняет ни одного бита. Меняется только то,
  как эти биты толкуются.
