# День 1. Задачи

Каждая задача — один файл `NN-имя.c` в этом каталоге. Пишите прямо здесь, рядом
с условиями. У задач 1–4 скелеты с готовым `main`, разбором ввода и печатью уже
лежат рядом: открывайте их и заполняйте места, помеченные `TODO`. В задаче 5
скелета нет намеренно: функций там две, а печатать надо одну строку.

```sh
make            # соберёт все .c в этом каталоге, с -Wall -Wextra и санитайзерами
./01-binary     # запустить
make clean
```

Собираться должно **без единого предупреждения**.

**В скелетах есть записи из следующих дней.** `main`, разбор ввода, печать и
самопроверка написаны целиком, и в них встречаются `argc` и `argv`, `struct`,
выражение `sizeof arr / sizeof arr[0]`, строковые `strcmp` и `snprintf`.
Массивы и указатели разбираются во второй день, структуры — в третьем и
четвёртом, строки — в четвёртом. Трогать этот код не требуется, и вопросов к
защите по нему нет.

Три записи из второго дня понадобятся вам уже сегодня, в том коде, который вы
пишете сами:

- **Тип `bool`** из `<stdbool.h>` со значениями `true` и `false` — задачи 3 и 4.
- **Массив и обращение по индексу** — задача 2. `static uint8_t byte_bits[256]`
  заводит 256 ячеек типа `uint8_t`, пронумерованных от 0 до 255; `byte_bits[i]`
  читает и записывает ячейку номер `i`. Запись та же, что у списка в Python,
  но размер задан заранее и не меняется.
- **Указатель в сигнатуре** — задача 4:
  `bool safe_add(int a, int b, int *out)`. Устройство указателей — второй день;
  сегодня достаточно правила: `*out = значение` записывает значение в
  переменную вызывающего, адрес которой пришёл в `out`. Со стороны вызывающего
  это тот же `&`, что в `scanf("%d", &n)`.

У каждого скелета есть встроенные краевые случаи — они запускаются одной
командой:

```sh
./01-binary --check
```

Что именно проверяется и на что смотреть — в конце каждого условия, в разделе
«Проверьте себя».

Задачи 1–3 сделайте обязательно. Задача 4 — главная на сегодня, к ней больше
всего вопросов на защите. Задача 5 — если дойдете.
