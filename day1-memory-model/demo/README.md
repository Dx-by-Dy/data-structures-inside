gcc -std=c11 -Wall -Wextra 06-division.c -o 06-division && ./06-division

разных ответах — объясните, как такое возможно.

## 07-negative-index.c

```sh
gcc -std=c11 -Wall -Wextra 07-negative-index.c -o 07-negative-index
./07-negative-index
```

Самый частый способ разложить значение по корзинам — взять остаток от хеша по
числу корзин. Посчитайте в питоне:

```python
>>> -12345 % 16
```

До запуска: что даст та же запись в C и чем закончится обращение по такому
индексу?

Вторая половина вывода показывает выражение `((h % size) + size) % size`.
Разберите его: почему внешний остаток нужен и почему он не портит те случаи,
где всё и так было в порядке. К этому выражению вы вернётесь на пятом дне.
