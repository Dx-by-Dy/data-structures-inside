# Задача 1. Функция, которая меняет ваши переменные

*Разминка. Нужна, чтобы привыкнуть: в C аргументы всегда копируются, и
единственный способ это обойти — передать адрес.*

## Что написать

Программу `01-swap.c` с тремя функциями:

```c
void swap(int *a, int *b);                     /* меняет местами два числа */
bool divmod(int a, int b, int *q, int *r);     /* частное и остаток сразу */
void minmax(int a, int b, int *min, int *max); /* меньшее и большее сразу */
```

Программа читает пары чисел до конца ввода и для каждой печатает четыре
строки.

```
$ printf '7 2\n-9 4\n5 0\n' | ./01-swap
a = 7, b = 2
  divmod: 7 / 2 = 3, остаток 1
  minmax: min = 2, max = 7
  swap:   a = 2, b = 7
a = -9, b = 4
  divmod: -9 / 4 = -2, остаток -1
  minmax: min = -9, max = 4
  swap:   a = 4, b = -9
a = 5, b = 0
  divmod: не определено
  minmax: min = 0, max = 5
  swap:   a = 0, b = 5
```

Обратите внимание: `divmod` считает по правилам C, а не Python. Округление к
нулю, знак остатка совпадает со знаком делимого — то же самое разбиралось
вчера в задаче 3.

## Сначала на Python

Напишите на Python функцию, которая меняет местами два числа:

```python
def swap(a, b):
    a, b = b, a

x, y = 1, 2
swap(x, y)
print(x, y)
```

Печатается `1 2`: снаружи ничего не изменилось. При этом строка `x, y = y, x`
прямо в вызывающем коде работает прекрасно.

Объясните себе, почему так, **до** того, как писать сишную версию: что именно
получает функция и что меняет присваивание внутри неё. Тот же вопрос про
сишный `swap` задаётся на защите. В Python это обходят возвратом кортежа:

```python
def swap(a, b):
    return b, a

x, y = swap(x, y)
```

А `divmod(7, 2)` в Python и вовсе встроенная функция, возвращающая пару.

В C кортежей нет. Скажите, что остаётся, и покажите это в сигнатурах трёх
функций выше. `divmod` возвращает `bool`, а сами числа кладёт по адресам `q` и
`r` — объясните, почему нельзя было вернуть частное значением.

## С чего начать

В каталоге лежит `01-swap.c` — скелет с готовым `main` и тремя пустыми
функциями. Он собирается и запускается, печатая заведомо неверные числа.
Работы там ровно три места, помеченные `TODO`; `main` менять не нужно.

## Требования

- `#include <stdbool.h>` для `bool`.
- Ни одна из трёх функций не печатает ничего сама. Печатает `main`.
- `divmod` возвращает `false` и **не трогает** `*q` и `*r`, если результат не
  определён.
- Собирается без предупреждений.

## Проверьте себя

```sh
./01-swap --check
```

Он сам сравнивает то, что вернули ваши функции, с правильными ответами и
печатает `ok` или `ОШИБКА` на каждую проверку, а в конце — «сошлось N из M».
Код возврата не ноль, если что-то разошлось, поэтому проверку можно повесить в
конец сборки:

```sh
./01-swap --check && echo "все три функции сошлись"
```

Прогоняются двенадцать пар: `b == 0`, `INT_MIN / -1`, нулевое делимое, равные
числа, обе комбинации знаков. На каждой проверяются все три функции, а на
парах, которые делить нельзя, — ещё и то, что `divmod` не тронул `*q`.

Два случая — те же, что вчера в задаче 3 первого дня, и оба ломают программу,
если их не проверить до деления. Скажите, какие именно, прежде чем смотреть на
вывод.

Отдельно посмотрите на строку, где `a` и `b` равны: `minmax` должна отработать
и на ней, а `swap` — не испортить числа.

Последней строкой скелет печатает в скобках, что осталось в `q` после вызова
`divmod(7, 2, &q, &q)`, где оба адреса совпадают. Сверки здесь нет намеренно:
ответ зависит от того, в каком порядке ваша функция пишет по адресам. Разберите
его по своему коду — этот случай разбирается на защите.

## Подсказки

- Внутри `swap` работать надо со значениями по адресам: `*a`, `*b`. Какого
  типа при этом временная переменная — решите сами; на защите спросят, почему
  именно такого.
- Проверять `q` и `r` на `NULL` в этой задаче не нужно: вызываете вы сами.
- Читать пары до конца ввода: `while (scanf("%d %d", &a, &b) == 2) { ... }`.
- Порядок печати в примере — `divmod`, `minmax`, `swap`. Если поменять его,
  числа в последних строках будут другими; убедитесь, что понимаете, почему.
