# Задача 5. Список ссылок

*Со звёздочкой. Ответ на вопрос дня, собранный руками: массив, элементы
которого — не числа, а адреса чисел. Именно так устроен питоновский список.*

## Что написать

Программу `05-refs.c`, которая читает до восьми чисел, строит из них «список
ссылок» и показывает разницу между копированием адресов и копированием
значений.

```c
void copy_pointers(int **dst, int *const *src, size_t n);
void copy_values(int **dst, int *const *src, size_t n, int *storage);
void print_list(const char *label, int *const *list, size_t n);
```

```
$ printf '10 20 30 40 50\n' | ./05-refs
original:  10 20 30 40 50
sizeof original    = 64 (весь массив, 8 ячеек)
sizeof original[0] = 8 (одна ячейка — это указатель)

после copy_pointers и *shallow[0] = 999:
  original: 999 20 30 40 50
  shallow:  999 20 30 40 50

после copy_values и *deep[1] = 777:
  original: 999 20 30 40 50
  deep:     999 777 30 40 50
```

Устройство такое. Сами числа лежат в обычном массиве `int values[8]`. «Список» —
это отдельный массив `int *original[8]`, в котором лежат адреса элементов
`values`. Печать списка разыменовывает каждый элемент: `*list[i]`.

Одна из двух функций копирования делает так, что две «переменные» показывают на
одни и те же числа, а вторая — так, что не показывают. Скажите по сигнатурам,
какая какая, до того как писать тела.

## Сначала на Python

Вот вопрос дня целиком:

```python
a = [1, 2, 3]
b = a
b.append(4)
print(a)          # [1, 2, 3, 4]
print(a is b)     # True
```

И то же самое с копией:

```python
a = [[1], [2]]
b = a[:]          # «копия»
b[0].append(9)
print(a)          # [[1, 9], [2]]
print(a[0] is b[0])
```

Второй пример важнее первого. Объясните его через слово «адрес» — и скажите,
какая из двух ваших функций соответствует `a[:]`.

И последняя пара проверок — про `sizeof original`. Объясните это число и

Померьте заодно размер списка:

элемента вашего массива и скажите, что из этого следует про содержимое
питоновского списка. Тот же вопрос будет на защите.

Обратите внимание и на то, что размеры растут не гладко: соберите список через
`append` и померьте после каждого шага. Откуда берётся запас — вопрос третьего

## Требования

- `int *const *src` в сигнатурах разберите справа налево и будьте готовы
  прочитать вслух и объяснить, что именно эта запись запрещает. Проверить себя
  можно опытом: попробуйте внутри `copy_pointers` написать `src[0] = NULL` и
  `*src[0] = 0` и посмотрите, какая из двух строк не соберётся.
- Никакой динамической памяти: `storage` — обычный массив в `main`.
  `malloc` будет завтра.
- `print_list` печатает значения, а не адреса: адреса на каждом запуске разные,
  сравнивать их в выводе бессмысленно.
- Собирается без предупреждений.

## Подсказки

- `int *original[8]` — это массив из восьми указателей. Читается так же справа
  налево: `original` — массив, элементы которого `int *`.
- Заполнение: `original[i] = &values[i];`
- Печать элемента: `*list[i]`. Скобки не нужны: индексация связывает сильнее
  разыменования.
- В `copy_values` каждому элементу нужно своё место в `storage`, поэтому
  `dst[i] = &storage[i]`, а не `dst[i] = &storage[0]`.
