# День 2. Задачи

Каждая задача — один файл `NN-имя.c` в этом каталоге. Пишите прямо здесь, рядом
с условиями. У задач 1, 2, 4 и 5 скелеты с готовым `main`, разбором ввода и
печатью уже лежат рядом: открывайте их и заполняйте места, помеченные `TODO`.
В задаче 3 скелета нет намеренно — способ вернуть массив в исходное состояние
вы должны найти сами.

```sh
make            # соберёт все .c в этом каталоге, с -Wall -Wextra и санитайзерами
./01-swap       # запустить
make clean
```

Собираться должно **без единого предупреждения**.

У каждого скелета есть встроенные краевые случаи — они запускаются одной
командой:

```sh
./01-swap --check
```

Что именно проверяется и на что смотреть — в конце каждого условия, в разделе
«Проверьте себя».

Задачи 1–3 сделайте обязательно. Задача 4 — главная на сегодня, к ней больше
всего вопросов на защите. Задача 5 — если дойдете; она напрямую отвечает на
вопрос дня.

Все пять задач начинаются с питоновского варианта. Это не разминка перед
настоящей работой: расхождение между тем, что делает Python, и тем, что
приходится написать на C, и есть содержание каждой задачи.

Вопросы к защите — [../defense/questions.md](../defense/questions.md), они
открыты прямо сейчас. Посмотрите их **до** того, как начнёте решать: половина
из них подсказывает, на что смотреть.
