# Демонстрации четвёртого дня

Пятнадцать маленьких программ. Запустите каждую сами:
адреса на вашем экране будут другими, чем на лекции.

**Здесь только команды и вопросы.** Ни вывода программ, ни объяснений: всё,
что нужно для ответа, было на лекции или добывается запуском. На каждый вопрос
отвечайте **до** запуска, письменно или вслух, а потом проверяйте себя. Место,
где предсказание разошлось с выводом, и есть то, что вы сегодня узнали.

Всё снималось на учебной машине: `gcc 15.2`, Linux x86-64. Конкретные адреса
не воспроизводятся даже от запуска к запуску, поэтому сравнивать надо не
числа, а расстояния между ними и порядок.

Сегодня рядом с терминалом полезно держать открытый `python3`: половина
вопросов — про то, чем питоновская строка отличается от сишной, и ответ

## 15-pyobject.c

Это вопрос дня.

```sh
gcc -std=c11 -Wall -Wextra 15-pyobject.c -o 15-pyobject && ./15-pyobject
```

Структура повторяет устройство целого числа внутри CPython. Откройте питон и
посмотрите `sys.getsizeof(1)`. Найдите это же число в выводе программы.

`sizeof` структуры и «заголовок плюс одна цифра» — разные числа. Объясните
разницу и скажите, какое из двух чисел печатает `sys.getsizeof`.

Последняя таблица говорит, сколько байт занимает число из `k` цифр. Проверьте
в питоне три значения:

```python
import sys
for k in (1, 2, 3):
    print(k, sys.getsizeof(2 ** (30 * k - 1)), sys.getsizeof(2 ** (30 * k)))
```

Скажите, почему в каждой паре второе число больше первого, и почему граница
проходит именно по степени 30.

Теперь то же самое для строки:

```python
import sys
print(sys.getsizeof(""), sys.getsizeof("a"), sys.getsizeof("ab"))
```

Разность соседних чисел даёт размер одного символа, а первое число — размер
заголовка. Назовите оба и скажите, что, кроме длины, обязано лежать в этом
заголовке, чтобы `len(s)` и `s in d` работали быстро.
