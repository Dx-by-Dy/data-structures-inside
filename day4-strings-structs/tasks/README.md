# День 4. Задачи

Каждая задача — один файл `NN-имя.c` в этом каталоге. Пишите прямо здесь, рядом
с условиями. У задач 1, 3, 4 и 5 скелеты с готовым `main`, разбором ввода и
печатью уже лежат рядом: открывайте их и заполняйте места, помеченные `TODO`.
В задаче 2 скелета нет намеренно — там `main` и есть половина работы.

```sh
make            # соберёт все .c в этом каталоге, с -Wall -Wextra и санитайзерами
./01-cstring    # запустить
make clean
```

Собираться должно **без единого предупреждения**, и санитайзер при завершении
обязан молчать.

У каждого скелета есть встроенные краевые случаи — они запускаются одной
командой:

```sh
./01-cstring --check
```

Что именно проверяется и на что смотреть — в конце каждого условия, в разделе
«Проверьте себя».

Задачи 1–3 сделайте обязательно. Задача 4 — главная на сегодня, и к ней больше
всего вопросов на защите. Задача 5 — если дойдёте; она же самая близкая к
завтрашнему дню.

Все пять задач начинаются с питоновского варианта. Сегодня сравнение особенно
прямое: третья задача объясняет, почему строку собирают через `join`, а пятая
разбирает по байтам то, что показывает `sys.getsizeof`.

Со вчерашнего дня остаются в силе оба требования: собирается без
предупреждений и санитайзер при завершении молчит. К ним добавляется третье,
специфичное для строк: **у каждой строки в куче есть ровно один владелец**.
Строка, скопированная в структуру, принадлежит структуре; строка, возвращённая
функцией, — вызывающему.

Вопросы к защите — [../defense/questions.md](../defense/questions.md), они
открыты прямо сейчас. Посмотрите их **до** того, как начнёте решать.
